# The Meeting That Should Have Been an Email

Entry for the [make.fun bounty](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9): one line that makes a meeting-that-should-have-been-an-email funny.

`main.ts` writes the single line to `/output/entry.txt`. Run it with Node 22:

```
node main.ts
```

The line is built from two beats — the promise on the calendar invite, then the punch: a second meeting scheduled to figure out what the first one was for. No setup, no second sentence, every word earning its place.
